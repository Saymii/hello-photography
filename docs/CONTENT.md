# Adding posing content

Edit `app/src/main/assets/poses.json` for illustrated guides and `photo-poses.json` for photo guides, then run `python3 tools/validate_content.py`. Each pose has a unique stable integer `id`, display `name`, `category`, structured `subject`, `style`, `location`, `position`, `difficulty`, boolean `premium`, and original `steps`, `hands`, `feet`, `face`. Do not reuse IDs: Room favorites refer to them. Categories populate dynamically; update user-facing category labels and curated category controls when adding a category.

The original 48 guides use Compose Canvas artwork, labeled as original illustrations. The additional owner-supplied collection uses AI-generated photo references, labeled with their source. `PosePhoto`, `PoseCatalog` and Coil load bundled references from `assets/photos/`; source, credit, authorization, collection and accessible alt-text metadata are required. See [PHOTO_COLLECTION.md](PHOTO_COLLECTION.md) for current counts, stable IDs, preserved originals, mobile copies and the import/review workflow.

Obtain appropriate distribution authorization and retain provenance and any applicable source/service license evidence. Do not invent a stock-photo license or model release. Keep complete hands, feet and relevant props visible in references. Review AI-generated anatomy and write physically achievable instructions. Bundled images work offline. Future remote downloads would require implemented storage quotas, integrity checking, deletion and premium authorization. Do not scrape reference photographs. Adapt instructions with inclusive language and subject comfort first.

An admin can edit and validate bundled JSON through a reviewed repository change. Runtime remote publishing/upload is not implemented. The planned authenticated admin workflow and draft rules are described in RELEASE.md; do not expose unrestricted storage writes or put administrator credentials on the device.

## Images and languages

Earlier unapproved image batches and the RAR archive remain excluded, including as visual inspiration. The owner separately identified the new collection as AI-generated and requested its inclusion on 19 October 2026. Preserve that distinction in source records and future imports. The available sources comprise 39 of the planned 48 photos; nine are still missing. The app must not substitute older excluded uploads or duplicate photos to reach a count.

Illustrations are drawn by `ui/OriginalPoseArt.kt`; posture and category determine the artwork. Keep existing pose IDs and canonical English filter values stable. Add translated text entries to `poses-am.json` (`id`, `name`, `steps`, `hands`, `feet`, `face`). `PoseTranslations` caches Amharic text and falls back to English when a translation is absent, while retaining photo metadata. Add a display category translation to `categoryLabel` without changing stored category values. Validate locale IDs and run translation/catalog tests before release; do not advertise complete translated new content without review.

The Academy curriculum is original bundled text in `domain/Academy.kt`, with paired English/Amharic lesson bodies, quiz choices and explanations. Keep lesson IDs stable so progress survives updates. Quiz correctness gates the completion UI. Marking a course premium shows its syllabus and routes to the subscription screen; it does not create a purchase entitlement.
