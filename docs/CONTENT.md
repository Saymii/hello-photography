# Adding original content

Edit `app/src/main/assets/poses.json` and run `python3 tools/validate_content.py`. Each pose has a unique stable integer `id`, display `name`, `category`, structured `subject`, `style`, `location`, `position`, `difficulty`, boolean `premium`, and original `steps`, `hands`, `feet`, `face`. Do not reuse IDs: Room favorites refer to them. Categories populate dynamically. Add future translations through Android string resources and locale-specific catalogs; the present sample is English only.

The existing artwork is drawn by Compose Canvas and labeled as an original illustration, rather than a photographic reference. Optional bundled photo references are supported by `PosePhoto`, `PoseCatalog` and Coil. Add reviewed entries to `photo-poses.json`, with actual assets under `assets/photos/` and source, credit, license, collection and accessibility metadata. Obtain explicit redistribution rights and retain the original source/license evidence. Keep complete hands, feet and relevant props visible in references. Bundled images can work offline; remote downloads require implemented storage quotas, integrity checking, deletion and premium authorization. Do not scrape reference photographs. Adapt instructions with inclusive language and subject comfort first.

An admin can edit and validate the bundled JSON today through a reviewed repository change. Runtime remote publishing/upload is not implemented. The planned authenticated admin workflow and draft rules are described in RELEASE.md; do not expose unrestricted storage writes or put administrator credentials on the device.


## Upgrade content and language

The earlier unapproved image batches and RAR remain excluded, including as visual inspiration. On 19 October the owner requested a new 48-photo collection. That new set is handled separately: pending files are staged outside Git until rights and the complete collection are reviewed. See [PHOTO_COLLECTION.md](PHOTO_COLLECTION.md). Existing illustration artwork is drawn by `ui/OriginalPoseArt.kt`; posture and category determine the illustration. New poses should use stable IDs and canonical English filter values, plus translated text entries in `poses-am.json` (`id`, `name`, `steps`, `hands`, `feet`, `face`). `PoseTranslations` caches Amharic copy and falls back to the original guide if an optional translation is missing. Add a display category translation to `categoryLabel` without changing canonical stored category values. Validate matching locale IDs and run translation/catalog tests before release.

The Academy curriculum is original bundled text in `domain/Academy.kt`, with paired English/Amharic lesson bodies, quiz choices and explanations. Keep lesson IDs stable so progress survives updates. Quiz correctness gates the completion UI. Marking a course premium shows its syllabus and routes to the subscription screen; it does not create a purchase entitlement.
