# Adding original content

Edit `app/src/main/assets/poses.json` and run `python3 tools/validate_content.py`. Each pose has a unique stable integer `id`, display `name`, `category`, structured `subject`, `style`, `location`, `position`, `difficulty`, boolean `premium`, and original `steps`, `hands`, `feet`, `face`. Do not reuse IDs: Room favorites refer to them. Categories populate dynamically. Add future translations through Android string resources and locale-specific catalogs; the present sample is English only.

The existing art is generated by Compose Canvas and is intentionally labeled placeholder. It is not a photographic body-position demonstration. To add photos, obtain explicit redistribution rights, retain source/license and release evidence, strip unnecessary metadata, create efficient WebP variants, add stable image paths to the schema/parser and use Coil AsyncImage with content descriptions, placeholders and errors. Bundled images can work offline; remote downloads require implemented storage quotas, integrity checking, deletion and premium authorization. Do not scrape reference photographs. Adapt instructions with inclusive language and subject comfort first.

An admin can edit and validate the bundled JSON today through a reviewed repository change. Runtime remote publishing/upload is not implemented. The planned authenticated admin workflow and draft rules are described in RELEASE.md; do not expose unrestricted storage writes or put administrator credentials on the device.


## Upgrade content and language

All images sent in this conversation are excluded, including as visual inspiration. Current artwork is drawn entirely by `ui/OriginalPoseArt.kt`; posture and category determine the illustration. New poses should use stable IDs and canonical English filter values, plus translated text entries in `poses-am.json` (`id`, `name`, `steps`, `hands`, `feet`, `face`). `PoseTranslations` caches Amharic copy and falls back to the original guide if an optional translation is missing. Add a display category translation to `categoryLabel` without changing canonical stored category values. Validate matching locale IDs and run translation/catalog tests before release.

The Academy curriculum is original bundled text in `domain/Academy.kt`, with paired English/Amharic lesson bodies, quiz choices and explanations. Keep lesson IDs stable so progress survives updates. Quiz correctness gates the completion UI. Marking a course premium shows its syllabus and routes to the subscription screen; it does not create a purchase entitlement.
